# Teaching Checkpoints（知识点清单与提问范例）

> Checkpoint 的操作协议见 SKILL.md §教学检查点机制。本文件是每个步骤可用的知识点清单与提问范例。
>
> **重要框架**：本 Skill 是 **AI 现场示范 + 学生观摩答题**模式。下表所有问题都应统一改写为"**回顾示范**"语气：
>
> - ❌ "你应该用什么切分？" / "你怎么决定 k=3？"
> - ✅ "我刚才用了 `stratify=y`，你能说出我在防什么吗？" / "我刚才把 k 设为 3 而不是 5，你能猜到我的依据吗？"
>
> 下表的提问示例已尽量按这个口径写。从中**挑 1-3 条与本次学生任务真正相关的**，再按 AI 刚刚跑出的具体代码/结果替换占位符（字段名、数字、类别名），不要全部堆上来。

## Step 0 — 任务模式判定

| 知识点 | 提问范例（回顾示范口吻） | 及格线 |
|---|---|---|
| 分析单位 | "我把本次任务的分析单位判定为 X（具体填：学生 / 订单 / 时间段 / 文档），你能说说我的依据是什么吗？" | 能从列名/数据字典推断 |
| 监督 vs 无监督 | "我这次决定做 X 任务（填具体模式）而不是 Y，关键依据是数据里有没有 target 列。你看出来我是怎么判断的吗？" | 能指出有无 y |
| 预测 vs 描述 | "我把任务归为'预测'而不是'解释'，这两个词的区别你能在本次数据上举例说明吗？" | 区分因果/预测/描述 |

## Step 1 — Context Card

| 知识点 | 提问范例（回顾示范口吻） | 及格线 |
|---|---|---|
| 决策代价 | "我在 Context Card 里把'误判为违约'标成最昂贵错误。你同意吗？如果反过来更贵，哪里会变？" | 能区分 FP 和 FN 的代价 |
| 部署时可得字段 | "我把字段 X 列为'预测时拿不到'、字段 Y 列为'当下可得'。你能复述我的判断依据吗？" | 能判断事前/事后 |
| 目标外推边界 | "我在 Context Card 里写'结论仅适用于某年某校'。你能说出我为什么加这个限制吗？" | 能说清覆盖范围 |

## Step 2 — Data Audit

| 知识点 | 提问范例（回顾示范口吻） | 及格线 |
|---|---|---|
| 缺失机制（MCAR / MAR / MNAR） | "我刚才发现 income 缺失 30% 且与 city 高度相关。我由此怀疑是机制性缺失而不是随机缺失——你能重述我的推理吗？" | 能区分随机 vs 机制性 |
| Group 泄漏 | "我刚才没用 `train_test_split(shuffle=True)`，因为同一个学号出现了多次。你能说清我在防什么吗？" | 能说出"同一实体跨 train/test" |
| 编码哨兵值 | "我把 age 列里的 -1 全部替换成 NaN。你理解我这一步在防什么吗？" | 能识别哨兵值 → 不能直接当数字用 |
| 重复记录 | "我跑了重复行检测，发现 1200 行重复。我没直接 drop，而是先看了一眼。你觉得我在犹豫什么？" | 能举"多次购买"之类合理重复的例子 |
| 时间单调性 | "我刚发现时间戳里 2020-12 的记录夹在 2019 年数据之间。我标注为可疑。你能猜到常见原因吗？" | 想到时区 / 回填 / 数据修订 |

## Step 3 — 特征 & 泄漏

| 知识点 | 提问范例（回顾示范口吻） | 及格线 |
|---|---|---|
| 泄漏的四种形态 | "我刚才把 `final_default_flag` 从特征里剔除了。你能重述我的理由吗？" | 能识别 target leakage |
| Pipeline vs 手工预处理 | "我把 `StandardScaler` 放进了 `Pipeline`，而不是先对 `X_all` 做 `fit_transform` 再切分。你能说出我在防哪条泄漏路径吗？" | 能指出先 fit 全量 = 测试集信息漏进 scaler |
| 分类变量编码 | "我对性别列用了 `OneHotEncoder` 而不是 `LabelEncoder(0,1,2)`。你能说出两者的关键区别吗？" | 能区分有序 vs 无序 |
| 高基数类别 | "我刚才看到邮编有 5000 个不同值，就没对它做 one-hot。你能猜到我的顾虑吗？" | 能想到维度爆炸 / target encoding / embedding |
| 时间特征 | "我只允许用 `t-1` / `t-7` 的 lag 作为特征，没用 `t+1`。你能说出我遵守的是哪条纪律吗？" | 能说出"别让未来信息进模型" |

## Step 4 — Baseline

| 知识点 | 提问范例（回顾示范口吻） | 及格线 |
|---|---|---|
| Dummy baseline 的作用 | "我刚跑 `DummyClassifier(strategy='most_frequent')`，得到 accuracy=0.92。你觉得这个数字对后续建模意味着什么？" | 能想到类别不平衡、accuracy 失效 |
| 逻辑回归可解释性 | "我打印了逻辑回归系数，其中 age 是 0.3。如果有同学说这代表'年龄增加 1 岁，违约概率增加 0.3'，你同意吗？" | 能识别错误解读，指出是 log-odds |
| 不需要深模型的信号 | "Logistic 已经 AUC=0.95。我在考虑要不要上 fastai。你觉得我应该怎么判断？" | 能说"收益递减 / 可解释性 / 部署成本" |
| K-means 的 k 选择 | "我先跑了 k=3 的 KMeans，而不是 k=5 或 k=10。你能猜出我的依据吗？" | 能提 elbow / silhouette / 业务可解释 |

## Step 5 — 切分 + 评估

| 知识点 | 提问范例（回顾示范口吻） | 及格线 |
|---|---|---|
| split-before-fit | "我把 `StandardScaler` 放进 `Pipeline` 里。如果我改成先 `fit(X_all)` 再切分，你能说出具体会在哪一步出泄漏吗？" | 能指出 test 信息漏进 scaler |
| Stratified | "我刚才用了 `stratify=y`。如果我不写这个参数，99:1 的类别分布会出什么问题？" | 小类可能完全没进 test |
| 时间切分 | "我这次没用 `train_test_split(shuffle=True)`，而用了 `TimeSeriesSplit`。你能重述我的理由吗？" | 不能用未来数据预测过去 |
| Group 切分 | "我刚用了 `GroupKFold` 按学号切分。如果改成普通 KFold，你能预测一下会发生什么吗？" | 同一实体跨 train/test，伪高分 |
| 指标选择 | "我把 Recall 列为主指标、把 Accuracy 降为参考。你能猜到我的判断依据吗？" | 漏报代价高、类别不平衡 |
| test 的纪律 | "我规定 test 集只跑一次。如果我在 test 上看到结果不好，又回去改特征再跑一次，你能说出问题在哪吗？" | 等价泄漏，test 不再独立 |

## Step 6 — 迭代模型

| 知识点 | 提问范例（回顾示范口吻） | 及格线 |
|---|---|---|
| Bias vs Variance | "我刚才看到 train F1=0.99、val F1=0.70。你能说出我会诊断为哪种问题吗？" | 过拟合（high variance） |
| RandomForest 调参重点 | "我把 `n_estimators` 设到 500，但把 `max_depth` 限到 10。你能说出我为什么只限 depth 不限 n？" | n_estimators 多一般不过拟合；depth/leaf 才是过拟合主因 |
| fastai `lr_find` | "我刚跑 `lr_find`，最终挑的 lr 不是 loss 最低那个点，而是下降最陡段。你能重述我为什么不选最低点吗？" | 最低点已接近发散、不稳定 |
| fine_tune vs fit_one_cycle | "我用了 `learn.fine_tune(2)` 而不是 `learn.fit_one_cycle(2)`。你能说出两者内部行为的关键区别吗？" | fine_tune 先冻结训 head，再解冻训全部 |
| 训练稳定性 | "同一段代码我跑了两次，分数差了 3%。我固定了 `random_state` 还差，你能猜出可能的来源吗？" | torch 的随机性、数据 shuffle、cudnn 等 |
| LDA coherence | "我选 num_topics=8 用的是 coherence 最高点，没用 perplexity。你能重述我的依据吗？" | perplexity 与人类主题判读相关性弱 |

## Step 7 — 误差分析

| 知识点 | 提问范例（回顾示范口吻） | 及格线 |
|---|---|---|
| 混淆矩阵解读 | "我刚画了混淆矩阵，左下角那一格（实际 1、预测 0）是 FN。在这个任务里，我把 FN 视为更严重的错。你能说出为什么吗？" | 能读矩阵 + 结合代价 |
| 子群体差异 | "我发现男女两组 recall 差 15%。我没直接上线模型。你能重述我的顾虑吗？" | 不能直接上；公平性风险 |
| 残差模式 | "我画的残差图呈漏斗形。我诊断为异方差。你能说出这个诊断的含义吗？" | 方差不稳定；可能需对数变换 |
| 高置信错例 | "我挑出了模型 99% 确信但错的 5 条样本。你能猜到最常见的 3 种原因吗？" | 标签错 / OOD / 数据录入错 |
| holdout 纪律 | "我做误差分析时只看了 validation 和 CV out-of-fold，没碰 holdout。你能重述我的纪律是什么吗？" | test 只做一次终评 |

## Step 8 — Streamlit 部署

| 知识点 | 提问范例（回顾示范口吻） | 及格线 |
|---|---|---|
| 训练-部署一致性 | "我把整个 `Pipeline`（含 Scaler）一起 `joblib.dump` 了，不只 classifier。你能说出我在防什么吗？" | 部署时预处理必须一致，否则输入分布错位 |
| `st.cache_resource` vs `st.cache_data` | "我用了 `@st.cache_resource` 装饰模型加载，而不是 `@st.cache_data`。你能说出两者的适用边界吗？" | resource=模型/连接；data=DataFrame 等 |
| 缺失值防御 | "我在 CSV 上传那段加了字段校验 + `st.stop()`。你能说出我在防什么情况吗？" | 用户上传少列 → 输入 schema 校验 |
| 输出概率 vs 类别 | "我的 app 同时输出了预测类别和每个类别的概率。你能说出为什么不只给类别？" | 决策阈值、高风险任务需概率 |
| 适用边界声明 | "我在 `st.expander` 里写了'不得用于真实招生决策'。你能说出为什么一定要写？" | 伦理 / 部署边界 |

## Step 9 — 反思

| 知识点 | 提问范例（回顾示范口吻） | 及格线 |
|---|---|---|
| 流程薄弱点 | "整个流程我跑下来，最让我觉得'数据不够'的是哪一步？如果让你重新做，你会重点改哪里？" | 能具体指出某一步 |
| 最隐蔽风险 | "我梳理了本次流程，你觉得哪一步'结果错了也最难被发现'？" | 能指出泄漏 / label noise / 子群体差异 |
| 外推 | "我在 model card 里写'本模型不适用于新学校'。你能重述我写这条的依据吗？" | 能说出分布差异 / covariate shift |

## 补讲模板（Checkpoint C5）

学生答不上来时：
1. 用 3-5 句人话讲清这个知识点；
2. 举一个反例或对照（"如果不这么做会怎样"）；
3. 换一个角度再问一次（不要重复同一问法）；
4. 仍不对 → 写入 `checkpoint-log.md` 标为"需教师介入"，推进到下一步。
