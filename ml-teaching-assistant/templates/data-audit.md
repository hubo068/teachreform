# Data Audit（数据审计 — 教学版）

> AI 在 Step 2 跑出审计代码后填写，结果会成为 Checkpoint 2 的素材。

## 基本规模
- 行数 / 列数：
- 字段类型分布（数值 / 类别 / 时间 / 文本）：
- 主键 / 唯一标识：
- 重复行数 + 是否合理：

## 缺失模式
- 各字段缺失率：
- 缺失是否随机（MCAR / MAR / MNAR 初判）：
- 是否有"缺失本身就是信号"的字段：

## 异常值与编码
- 数值字段超界 / 不可能值：
- 哨兵值（-1 / 999 / 9999）：
- 字符串字段奇怪取值（空格 / 全角 / 拼写变体）：

## 标签质量（监督任务）
- 标签定义是否稳定：
- 是否有主观标注 / 漏标 / 补录 / 事后修订：
- 类别分布（是否极不平衡）：

## Group / 时间结构
- 是否有同一实体（学号/病人/订单）多次出现：
- Group 列名 + 每 group 平均行数：
- 时间戳是否单调 / 是否有缺口 / 是否有未来时间：

## 多表 join 风险（如适用）
- 主表 + 副表清单：
- 是否存在 1:N 膨胀：
- as-of join 是否引入未来信息：

## 审计结论（决定下一步路径）
- [ ] 进入 Step 3（特征 + 假设）继续示范
- [ ] 仅做描述分析（不建模）
- [ ] 时间序列分支
- [ ] 停止建模 → 直接 Step 10 反馈报告

## 给学生的提示（Checkpoint 2 素材）
列 2-3 个本次审计中**最值得提问**的发现，例如：
- "income 缺失率 30%，且与 city 高度相关"
- "同一 student_id 平均出现 3.2 次"
- "时间戳里有 2030 年的记录"
